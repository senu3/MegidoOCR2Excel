# Phase 6 リリーステスト

リリース候補をWindowsで確認するための開発者向けチェックリストです。ユーザー向けの基本操作は `README.md` と `USER_GUIDE.md` にまとめ、この文書では再現条件と判定基準を扱います。

## 自動テスト

次のコマンドは同時に実行せず、上から順に実行します。Windowsでは複数のTkテストを並列実行すると、フォーカスや終了処理が相互に影響することがあります。

```powershell
uv run python -m compileall -q main.py launcher.py megido_ocr_excel scripts tests
uv run python -m unittest discover -s tests
uv run python launcher.py --check
```

判定基準:

- 構文検査にエラーがない
- 全テストが `OK` になる
- ランチャー確認が `ready: true`、`reason: 準備完了` になる

## OCR精度とExcel出力

`.samples` の正解CSVを使って、アプリと同じ認識経路を測定します。

```powershell
uv run python scripts/measure_speaker_ocr.py
uv run python scripts/measure_dialogue_ocr.py --save-crops C:\tmp\megido-dialogue-crops
```

確認項目:

- [ ] 話者名が既知の基準値から悪化していない
- [ ] 本文の差分をCSVと保存された切り出し画像で確認した
- [ ] 句読点・長音・三点リーダーなど、正規化で吸収する差を区別した
- [ ] 誤検出や空欄を、OCR調整と自動検出調整のどちらで扱うか判断した
- [ ] `b1.png`～`b3.png` を会話自動検出し、Excelを再度開ける
- [ ] `Errors` と `Notices` の内容が処理結果と一致する

## Sandboxie Plusでのクリーン検証

Sandboxie Plusは、uvを導入済みの同一Windowsユーザーで初回状態を繰り返す用途に使用できます。OS自体、PATH、フォント、GPUドライバーなどはホストと共通なので、完全な別PC検証の代わりではありません。今回の配布条件である「uv導入済み」は満たしたまま、ランチャー環境・アプリ設定・OCRモデルを隔離します。

### DefaultBoxの設定

ソースフォルダーは読み取り可能なままにし、書き込み許可には追加しません。次のパスだけをサンドボックス内へリダイレクトします。

```text
C:\Users\<ユーザー名>\AppData\Roaming\uv
C:\Users\<ユーザー名>\AppData\Local\uv
C:\Users\<ユーザー名>\AppData\Local\MegidoOCR2Excel
C:\Users\<ユーザー名>\.paddlex
```

Excelの試験出力先は、必要なフォルダーだけ直接アクセスを許可します。例:

```text
C:\Users\<ユーザー名>\Documents\test-image
```

インターネット接続と実行開始は許可します。設定後、DefaultBoxの「内容を削除」してから試験を開始します。

### 初回起動

- [ ] DefaultBoxの内容を削除した
- [ ] DefaultBox内で `MegidoOCR2Excel.cmd` を実行した
- [ ] ランチャーが「初回セットアップ」と表示する
- [ ] Pythonと依存パッケージの準備が完了する
- [ ] アプリが開き、OCR準備画面が表示される
- [ ] 「今は準備せず、範囲編集へ」でモデルを取得せず進める
- [ ] 開始方法画面の `Esc` と右上の閉じるボタンで、画像フォルダー未選択の編集画面へ進む
- [ ] 認識操作を行うとOCR準備画面へ戻り、「今回は認識せず戻る」が表示される
- [ ] 「ダウンロードして準備」で認識モデルを取得できる
- [ ] 準備後の再起動でOCR準備画面を繰り返さず、開始方法画面が表示される

### 基本操作

- [ ] `b1.png`～`b3.png` のフォルダーで「会話を自動検出」を選べる
- [ ] 画像件数と検出された会話件数が正しい
- [ ] 前後移動、除外、再実行が機能する
- [ ] `f.jpg` または `g.png` で新規テンプレートを作成できる
- [ ] 範囲追加、範囲編集、認識テストが機能する
- [ ] Excelを許可した一時フォルダーへ出力できる
- [ ] 出力したExcelを閉じて再度開ける
- [ ] アプリを閉じて再起動しても準備済み状態を維持する

### 修復連携

- [ ] アプリから「ランチャーで修復」を選ぶとアプリが閉じる
- [ ] ランチャーが修復状態で開き、依存環境を再構築する
- [ ] 修復後にアプリが再起動する
- [ ] OCRモデルを再ダウンロードしない
- [ ] OCRモデル保存先と端末設定が保持される
- [ ] 保存済みテンプレートは変更されない
- [ ] 未保存の編集がある場合は、修復へ移る前に確認が表示される
