# Megido OCR to Excel

メギド７２のストーリー画像から会話や指定範囲を読み取り、ExcelへまとめるWindows用アプリです。

## できること

- 会話画面と会話ログの自動検出
- 好きな範囲を読み取るテンプレートの作成
- 代表画像を使った認識テスト
- 複数画像のExcel出力と失敗画像の再実行

## 起動方法

事前に [uv](https://docs.astral.sh/uv/getting-started/installation/) を導入してください。

1. ファイルをすべて同じフォルダーに置く
2. `MegidoOCR2Excel.cmd` をダブルクリックする
3. 初回はランチャーの準備が終わるまで待つ

PowerShellから起動する場合は `.\run_app.ps1` を実行します。

## 初回のOCR準備

アプリが開いたら、OCR準備画面で次のどちらかを選びます。

- すぐに認識する: 「ダウンロードして準備」
- 範囲編集だけ行う: 「今は準備せず、範囲編集へ」

認識モデルは前者を選んだときだけ取得します。取得中はインターネット接続が必要です。

## 基本的な流れ

1. 「会話を自動検出」または「新規テンプレートを作成」を選ぶ
2. スクリーンショットのフォルダーを選ぶ
3. 読み取り範囲とExcel列を確認する
4. 「認識テスト」で結果を確認する
5. 「Excel出力」で保存する

操作の詳細は [ユーザーガイド](docs/USER_GUIDE.md) を参照してください。

## 困ったとき

- `uvが見つかりません` と表示される: uvを導入し、PowerShellやコマンドプロンプトを開き直す
- OCRの不足が表示される: アプリの「ランチャーで修復」を選ぶ
- アプリ自体が開かない: PowerShellで `.\run_app.ps1 --repair` を実行する

開発環境、内部構成、UI検証、精度測定は [開発ドキュメント](docs/DEVELOPMENT.md) にまとめています。
