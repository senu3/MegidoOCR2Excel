# Megido OCR to Excel

メギド７２のストーリーパートのスクリーンショットから会話や指定範囲を読み取り、Excelへ出力するツールです。

会話画面は画像ごとに読み取り範囲を自動検出できます。独自形式の画面には、読み取り範囲と列構成を保存するテンプレートを作成できます。

## できること

- 会話画面と会話ログの自動検出
- 任意の画面に合わせた読み取りテンプレートの作成
- 代表画像を使った認識テスト
- 複数画像のExcel出力と失敗画像の再実行

## ソース版の起動

現在はソース版を提供しています。先に [uv](https://docs.astral.sh/uv/getting-started/installation/) を導入し、`MegidoOCR2Excel.cmd` をダブルクリックしてください。専用ランチャーがアプリ用環境を準備してから起動します。

PowerShellから起動する場合は次のコマンドも使用できます。

```powershell
.\run_app.ps1
```

ランチャーはPaddleOCRの実行環境までを準備します。認識モデルはアプリが勝手に取得せず、初回画面で「ダウンロードして準備」を選んだときだけ取得します。「範囲編集だけ先に始める」を選ぶと、モデルを取得せずに編集を開始できますが、認識テストやExcel出力の前には準備が必要です。

PaddleOCR実行環境の不足をアプリが検出した場合は、「ランチャーで修復」を選べます。アプリ終了後にランチャーが依存パッケージを再インストールし、動作確認に成功するとアプリを再起動します。OCR認識モデル、テンプレート、端末設定は削除しません。

## 基本的な使い方

1. 「会話を自動検出」または「新規テンプレートを作成」を選ぶ
2. スクリーンショットのフォルダーを選ぶ
3. 必要に応じて読み取り範囲とExcel列を調整する
4. 「認識テスト」で代表画像の結果を確認する
5. 「Excel出力」で対象画像と保存先を確認する
6. Excelへ出力する

詳しい操作は [ユーザーガイド](docs/USER_GUIDE.md) を参照してください。

開発環境、UI検証モード、内部構成、精度測定については [開発ドキュメント](docs/DEVELOPMENT.md) にまとめています。
