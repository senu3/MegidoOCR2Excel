# Megido OCR to Excel

特定のノベルゲーム画面に寄せた、定型スクリーンショット用のOCRテンプレート作成ツールです。

会話画面は画像ごとに読み取り範囲を自動検出できます。独自形式の画像には、Canvasで読み取り範囲を作るテンプレート方式も利用できます。

## セットアップ

```powershell
uv sync
```

OCRバックエンドはPaddleOCRを標準で使用します。初回OCR時にPaddleOCRのモデルが自動ダウンロードされるため、初回だけ時間がかかります。モデルはユーザーディレクトリにキャッシュされます。

Tesseract OCRを比較用または退避用に使う場合のみ、追加依存とTesseract OCR本体をインストールしてください。

```powershell
uv sync --extra tesseract
```

- Tesseract OCR: https://github.com/UB-Mannheim/tesseract/wiki
- インストール時にJapanese language dataを選択

Tesseractのパスが自動検出されない場合は、アプリ内の「設定」でバックエンドを `tesseract` にしたうえで、実行ファイルのパスを指定してください。

```text
C:\Program Files\Tesseract-OCR\tesseract.exe
```

## 起動

```powershell
uv run python main.py
```

または:

```powershell
uv run megido_ocr_excel_app.py
```

## 基本フロー

1. 起動画面で「会話を自動検出」または「新規テンプレートを作成」を選ぶ
2. 画像フォルダを選択する。自動検出では各画像の会話形式と読み取り範囲が表示される
3. 新規テンプレートの場合は、セリフ、話者名、選択肢などの読み取り範囲をドラッグ作成する。保存済みテンプレートは右上の「…」メニューから読み込める
4. 必要に応じて項目名や順序を調整する
5. 「認識テスト」で代表画像の読み取り範囲とOCR結果をチェックする
6. 「Excel出力」で処理対象を確認・除外し、Excel出力先と出力設定を選んで「Excel出力」

画像はファイル名中の数字を考慮した自然順で処理します。たとえば `1.png, 2.png, 10.png` の順になります。

同じ画像内で繰り返すまとまりを1行ずつ出力する場合は、「範囲・列」の出力形式を `セットごとに1行` にします。セット種類は `会話（話者＋セリフ）`、`話者＋1行セリフ`、`見出し＋本文` から選べます。「セットを追加」から必要な範囲を順番にCanvasで指定すると、Excelでは `順序` とセット種類に応じた列へ出力されます。項目は見出し直下のセットに属し、右端のハンドルで別のセットまたは未割当へ移動できます。

Megidoの会話ログは、話者名の濃紺バーをアンカーとして各画像の会話位置を自動検出します。スクロール位置が変わっても完全な話者・セリフの組だけを上から順に出力し、画面上端のセリフ断片と画面下端で途切れた会話は除外します。除外理由はExcelの `Notices` シートに記録します。

`.samples/f.jpg` と `.samples/g.png` のような特殊な会話・カード形式は会話自動検出の対象外です。新規テンプレートで `話者＋1行セリフ` または `見出し＋本文` のセット種類を選び、範囲を手動設定します。

通常画面も画像ごとに自動分類します。濃紺バーのある通常会話、話者名と本文が意図的に空の演出、黒背景中央のナレーションをそれぞれ1会話として扱います。通常枠の上に補足セリフ候補がある画像は、認識テストで範囲を確認できます。

## 初期テンプレート

`.samples/megido_novel_template.json` は実スクリーンショットに合わせて座標調整するための仮テンプレートです。OCR範囲の基準画像としては実際のノベル画面を使ってください。

## 黒余白と座標補正

新規テンプレートは、画像全体ではなく黒余白を除いたゲーム画面領域を基準に座標を補正します。画像サイズや上下の黒余白が異なっても、ゲーム画面の配置が同じなら同じ読み取り範囲を利用できます。

- テンプレート保存時に基準画像のコンテンツ領域を保存
- 各画像で黒余白を検出し、コンテンツ領域間で座標を変換
- 認識テスト画面に黒余白補正の適用状態を表示
- 黒余白を安定して検出できない画像は、従来の画像全体スケーリングへフォールバック
- 現行テンプレートはセット定義と座標基準を明示して保存

会話ログなど画面レイアウト自体が異なる画像には、黒余白補正ではなく別テンプレートを使用してください。

## 保存と終了の保護

- 座標、項目、OCR設定、出力設定を変更すると、ウィンドウタイトルとテンプレート名に `*` が付きます。
- 未保存のまま別テンプレートを読み込む場合や終了する場合は、保存・破棄・キャンセルを選べます。
- OCRまたはExcel出力の処理中は、ファイル書き込みの中断を防ぐためアプリを終了できません。
- テンプレートとExcelは同じフォルダの一時ファイルへ書き切ってから置換します。保存に失敗した場合、既存ファイルは変更されません。

## 特化設定

ゲーム固有設定は共通の `OcrProfile` モデルから分離して定義します。現在のゲーム向け設定は `profiles/megido_novel.py` にあり、アプリ本体とOCRエンジンはこのモジュールを直接参照しません。通常UIでは範囲、項目名、項目順、後処理、Excel出力を調整し、OCR前処理や行分割などの初期値はプロファイル側で定義します。

別ゲームへ対応する場合は、次の単位でプロファイルを追加します。

- ID、表示名、アプリ名
- 既定OCRバックエンドと言語
- 座標変換の既定値
- 項目名の接頭辞と項目別OCRプリセット
- `profiles/__init__.py` のレジストリ登録と `megido_app_config.py` の有効プロファイル指定

プロファイルにはサンプル画像や `.samples` のパスは含めていません。共有しない検証用サンプルは、精度測定スクリプトの `--samples-dir` と `--template` で指定してください。

## 構成

- `megido_ocr_excel_app.py`: CustomTkinter UI
- `megido_ui_theme.py`: 黒紫ダークテーマ、寸法、主要文言
- `profiles/megido_novel.py`: このゲーム向けの既定OCRバックエンド、言語、項目別OCRプリセット
- `profiles/base.py`: ゲーム共通のプロファイルモデル
- `ocr_models.py`: テンプレート項目モデル
- `ocr_engine.py`: OCR、画像前処理、後処理、範囲スケーリング
- `excel_exporter.py`: Excel出力、エラーシート生成
- `batch_queue.py`: 自然順の画像キュー、除外、処理状態
- `template_store.py`: テンプレートJSON保存・読み込み
- `atomic_io.py`: テンプレートとExcelのアトミック保存

## ショートカット

- `Ctrl+Left`: 前の画像
- `Ctrl+Right`: 次の画像
- `Ctrl+S`: テンプレート保存
- `Ctrl+O`: テンプレート読み込み
- `Ctrl+Enter`: Excelへ一括出力
- `Alt+Up`: 選択項目を上へ
- `Alt+Down`: 選択項目を下へ
- `Esc` / `Ctrl+Z`: 直前の項目追加、削除、範囲変更を取り消し

## 項目カード操作

- 項目行の鉛筆アイコン、項目名のダブルクリック、または `F2`: その場で名前を編集
- 名前編集は `Enter` で確定、`Esc` でキャンセル。重複名は入力欄の下に表示
- 項目行の三点アイコンまたは右クリック: 編集、範囲選択、複製、削除メニュー
- 項目カード右端のグリップをドラッグ: Excel列順を変更

## Canvas操作

- 空いている場所をドラッグ: 新しい読み取り範囲を作成
- 既存の矩形内をドラッグ: 読み取り範囲を移動
- 既存の矩形の辺または角をドラッグ: 読み取り範囲をリサイズ
- セット出力時の番号ハンドルをドラッグ: セット内の全範囲を同時に移動
- セット出力時の中枠: 通常は非表示、項目を選択したときだけ個別調整用に表示
- セットの `↑ / ↓`: セット内の項目をまとめてExcel出力順ごと移動
- 各項目のドラッグハンドル: 別のセットまたは未割当へ移動（同じ種類がある場合は入れ替え）
- `画像ごとに1行` の項目行: OCR方式を範囲全体・行切り出しから変更
- `セットごとに1行` の項目行: 選択したセット種類に応じて、話者・セリフ、セリフ、見出し・本文などの割当を変更。会話用セットでは補足セリフも選択可能
- Canvasラベルをダブルクリック: 対応する項目名を編集
- 既存の矩形を右クリック: 項目名編集、複製、削除、直前操作の取り消し
- 作成や範囲変更を誤った直後: `Esc` / `Ctrl+Z` で取り消し
- チェックを外した項目: Canvas上ではグレー表示

## 認識テスト

- 現在の画像について、選択項目または全項目をテスト
- 選択中の項目について、読み取り範囲の拡大プレビューと認識結果全文を確認
- 生OCRと後処理後の結果が異なる場合は両方を表示
- 上部の前後ボタンで先頭・中央・末尾などの代表画像へ移動して再テスト
- 選択項目ごとにOCR方式を調整し、設定変更後に再テスト
- 基本設定の「テキスト整形」で、全ての行切り出し項目に共通する行のつなぎ方（空白なし・全角スペース・改行）と半角英数字・記号の全角化を設定
- 認識テストの結果はプレビューであり、Excel出力時には対象画像を改めて一括OCR

## テンプレート形式

- リリース用の正式形式は `format: image-ocr-to-excel-template`, `version: 1`
- 読み込み時に形式、バージョン、必須項目、対象プロファイルを検証
- 現在のプロファイルと `profile_id` が異なるテンプレートは読み込まない
- リリース前の旧バージョンや旧キー名に対する移行・互換読み込みは行わない
- 今後形式を変更する場合は `version` を更新し、必要になった時点で明示的な移行処理を設計

## Excel出力タブ

- 画像を自然順のキューで表示し、チェックを外した画像を今回の処理から除外
- ファイル名をクリックして、その画像をCanvasで確認
- 各画像の状態を `待機 / 処理中 / 完了 / 要再実行 / 除外` で表示
- シート名、上書き/追記、開始セルを設定
- 画像ファイル名列とヘッダー行の出力有無を設定
- 出力形式を `画像ごとに1行` または `セットごとに1行` から選択
- セット出力は、項目順ではなくテンプレートに保存した `set_id` と `slot_key`、セット定義で各列を対応付け
- 未割当、必要項目の不足、同じ種類の重複がある場合は出力前に具体的なエラーを表示
- 出力設定はテンプレートJSONに保存
- OCR結果が空だった項目や認識に失敗した項目は `Errors` シートに記録
- 会話ログの上端・下端で除外した不完全な会話は `Notices` シートに記録し、失敗分再実行の対象にはしない
- 意図的に空の話者なし会話は空欄の1行として保持し、空OCRエラーにはしない
- 補足セリフ候補は認識テストに表示し、対応会話と同じ話者の次の会話として自動出力する。必要な場合だけ「範囲を修正する」から調整
- `失敗分を再実行` は、成功済みの行を増やさず、失敗画像の前回行だけを上書き
- 再実行前に出力先や列構成を変えた場合は誤上書きを防ぐため、全画像の再出力が必要

## OCR精度測定

`.samples` の `*.png` と同名の `*.csv` を正解データとして比較します。
測定時もアプリと同じ会話自動検出、黒余白補正、補正ルール、テキスト整形を適用します。
会話ログのように同じ項目名が複数あるCSVは記載順に1会話ずつ比較し、結果を `b1.png#1` のように表示します。補足セリフは対応する話者を引き継いだ次の会話として比較します。
話者、セリフ本文ともに完全一致数を表示し、セリフ本文は全角・半角、空白、改行を正規化した一致数も併記します。

```powershell
uv run python scripts/measure_speaker_ocr.py
uv run python scripts/measure_dialogue_ocr.py
```

調整例:

```powershell
uv run python scripts/measure_speaker_ocr.py --preprocess white-glyph --scale 4 --threshold 190 --psm 6 --lang jpn
uv run python scripts/measure_dialogue_ocr.py --preprocess threshold --scale 3 --threshold 140 --psm 6 --lang jpn --csv-out C:\tmp\dialogue-ocr.csv
uv run python scripts/measure_dialogue_ocr.py --line-split detected --preprocess threshold --scale 3 --threshold 140 --psm 6 --lang jpn
uv run python scripts/measure_dialogue_ocr.py --line-split none
uv run python scripts/measure_dialogue_ocr.py --backend tesseract --tessdata-dir C:\tessdata_best --oem 1
```
