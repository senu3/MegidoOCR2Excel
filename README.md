# Megido OCR to Excel

メギド７２のストーリースクリーンショットから会話や指定範囲の文字を読み取り、検索・整理しやすいExcelファイルにまとめるWindows用アプリです。

## できること

- 会話画面、話者なし会話、ナレーション、会話ログから話者とセリフを自動検出する
- 任意の読み取り範囲とExcel列をテンプレートとして保存し、同じ形式の画像に再利用する
- 代表画像で認識結果を確認し、範囲や読み取り方法を調整する
- 複数画像をまとめてExcelへ出力し、空結果や失敗画像だけを確認・再実行する

## はじめる

### インストールして起動する

Windowsと、初回セットアップ中のインターネット接続が必要です。

1. [uvをインストール](https://docs.astral.sh/uv/getting-started/installation/)します。
2. [GitHub Releases](https://github.com/senu3/MegidoOCR2Excel/releases) の **Assets** からWindows用ZIPをダウンロードします。
3. ZIPをフォルダーごと展開します。
4. 展開先の `MegidoOCR2Excel.cmd` をダブルクリックします。
5. ランチャーに **「初回セットアップ」** と表示されたら、**「セットアップを開始」** を選びます。準備が終わるとアプリが開きます。
6. **「OCR認識モデルをダウンロード」** で **「ダウンロードして準備」** を選びます。

画面に **「準備完了」** と表示されれば、文字認識を使用できます。範囲編集だけを先に行う場合は、**「今は準備せず、範囲編集へ」** を選べます。

PowerShellから起動する場合は、展開先で次を実行します。

```powershell
.\run_app.ps1
```

### 最初のExcelを作る

会話スクリーンショットのフォルダーから、認識結果を確認してExcelへ出力する最短手順です。

1. **「開始方法を選択」** で **「会話を自動検出」** を選び、スクリーンショットが入ったフォルダーを指定します。
2. **「2. 認識テスト」** で **「全項目をテスト」** を選び、話者とセリフの **「認識結果」** を確認します。
3. **「3. Excel出力」** を開き、**「出力ファイル」** の **「選択」** から保存先を指定します。
4. **「Excel出力」** を選びます。

**「完了」** と表示され、指定した場所に `.xlsx` ファイルが作成されれば完了です。エラーがある場合は、同じファイルの `Errors` シートに対象画像と項目が記録されます。

## 詳しい使い方

[ユーザーガイド](docs/USER_GUIDE.md) では、次の操作を目的別に説明しています。

- 自動検出と新規テンプレートの使い分け
- 読み取り範囲、Excelの行単位、列順の編集
- 認識結果とテキスト整形の調整
- 出力対象、シート、追記・上書きの設定
- 失敗画像の再実行とOCR環境の修復

## 更新する

新しいWindows用ZIPを別のフォルダーへ展開し、`MegidoOCR2Excel.cmd` から起動します。OCRモデル、端末設定、保存済みテンプレートは引き継がれます。新しい版の動作を確認してから、古い展開フォルダーを削除してください。

## 起動できないとき

- `uv was not found` または `uvが見つかりません` と表示される

  uvをインストールし、PowerShellやコマンドプロンプトを開き直してから起動します。

- アプリに **「OCR実行環境が不足」** と表示される

  **「修復」** を選び、アプリを終了してランチャーの修復を実行します。

- アプリ自体が開かない

  展開先で次のコマンドを実行し、ランチャーから修復します。

  ```powershell
  .\run_app.ps1 --repair
  ```

詳しい症状別の対処は、[ユーザーガイドの「困ったとき」](docs/USER_GUIDE.md#困ったとき)を参照してください。解決しない場合は、[GitHub Issues](https://github.com/senu3/MegidoOCR2Excel/issues) で報告できます。
